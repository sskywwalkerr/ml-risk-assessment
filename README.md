# ML Пайплайн для оценки финансового ущерба

Этот проект представляет собой единый пайплайн машинного обучения для анализа сетевого трафика с оценкой финансового ущерба. Он включает: загрузку и предобработку данных, генерацию признаков, финансовую маркировку, обучение моделей, оценку результатов и визуализацию.

## Основные возможности
- **Загрузка и предобработка данных**: исправление некорректных символов, масштабирование, кодирование меток.  
- **Генерация признаков**: коэффициенты, статистические, временные признаки и оценки аномалий.  
- **Финансовые метки**: расчет базовой стоимости атаки, времени обнаружения, размера компании и общего ущерба.  
- **Модели**: Random Forest для классификации и регрессии с оценкой важности признаков.  
- **Обучение и оценка**: метрики классификации (accuracy, F1), регрессии (MAE, RMSE, R²), поддержка фильтрации только атак.  
- **Визуализация**: история обучения, важность признаков, ROC-кривые, матрицы ошибок, анализ регрессии.  
- **Конфигурация**: настраивается через `configs/full.yaml`.

## Структура проекта
- configs/ # YAML-конфиги
- data/ # Исходные и обработанные данные
- models/ # Сохраненные модели и метаданные
- results/ # Визуализации и результаты экспериментов
- src/ # Исходный код (данные, признаки, модели, обучение, утилиты)
- train_fulll.py # Основной скрипт для запуска пайплайна


## Быстрый старт
Установите зависимости и запустите пайплайн:
```bash
pip install -r requirements.txt
python train_full.py
```

Результаты:
- Модели сохраняются в models/
- Графики и визуализации — в results/
- Таблица среднего ущерба и метаданные — в models/
